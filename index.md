Zach Taylor:  

- Project Manager (responsible for coordinating the activities of the group and for liaison with the instructor to resolve issues affecting the group from time to time. The project manager should be: professional and responsible, a good organizer, and an effective communicator. His/her functions include: 1) Coordinating group activities, 2) Overseeing and managing activities, 3) Allocating roles, activities, and responsibilities, and 4) Coordinating and managing documentation activities.) 

- Use Cases:  

    - Trainer creates a class  

    - User earns achievements or badges 

    - User can make friends 

 

Lademi Aromolaran:  

- Requirements Engineer (leads the requirements effort) 

- Use Cases: 

    - User can set goals and track progress 

    - Self-paced exercise plans 

    - View dashboard 


Olivia Calusinski:  

- Project Librarian (keeps all meeting logs and makes all design artifacts available for the team) 

- Use Cases: 

    - User records a workout 

    - User records calorie intake, sleep, and weight 

    - User can view historical data 

 

Jonah Beck:  

- Design Engineer (leads the design effort) 

- Use Cases: 

    - User can login  

    - Trainer can modify an existing class or plan 

    - User can register for a trainer led class 

 

Owen Chipman:  

- Quality Assurance (oversees test case design, validation of requirements, design, etc.) 

- Use Cases: 

    - User management

    - Trainer statistics
